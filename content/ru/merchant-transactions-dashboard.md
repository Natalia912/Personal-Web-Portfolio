## Описание проекта

Дашборд для мерчантов, предназначенный для управления транзакциями, биллингом и API-ключами, с раздельными представлениями для пользователей и администраторов. Разработан самостоятельно на React, TypeScript и Vite, с использованием Chakra UI для компонентов, TanStack Query для загрузки данных, Zustand для управления состоянием и React Hook Form с Zod для валидации. Административная часть обрабатывает более 10 000 транзакций, а архитектура выстроена на принципах Evolution Design для удобства поддержки и масштабируемости.

### Ключевые функции

- **Управление транзакциями** — таблицы транзакций с пагинацией, поиском и фильтрацией по валюте, терминалу, диапазону дат (выбор через календарь) и статусу
- **Панель деталей транзакции** — клик по любой строке открывает боковую панель с полной информацией о транзакции без выхода из режима просмотра таблицы
- **Административные функции** — администраторы могут удалять или повторно запускать транзакции прямо из дашборда
- **Каскадные правила перенаправления терминалов** — администраторы могут создавать и редактировать правила перенаправления через форму, выбирая между простым перенаправлением (прямое сопоставление терминал-терминал) или пользовательским перенаправлением на основе настраиваемых диапазонов пропускной способности терминала и суммы транзакции
- **Управление мерчантами (админ)** — отдельные административные страницы для добавления пользователей-мерчантов и управления ими
- **Управление API-ключами** — пользователи могут просматривать и управлять собственными API-ключами прямо из дашборда
- **Обзор биллинга** — отдельный раздел биллинга для отслеживания использования и начислений
- **Управление аккаунтом** — пользователи могут изменять имя и фамилию, просматривать неизменяемый юзернейм, менять email (с подтверждением паролем), менять пароль (старый пароль, новый пароль, повтор) и выходить из аккаунта
- **Ролевой доступ** — пользователи имеют доступ к транзакциям только для чтения, тогда как администраторы обладают полным контролем над удалением, повторными запусками, управлением мерчантами и правилами перенаправления

### Технические особенности

- Выстроила архитектуру приложения на принципах Evolution Design, сохраняя поддерживаемость и масштабируемость кодовой базы по мере роста функциональности на пользовательской и административной сторонах
- Создала динамическую форму-конструктор правил для каскадных перенаправлений терминалов, поддерживающую два различных режима (простое сопоставление терминалов и правила на основе диапазонов пропускной способности и суммы транзакции) в рамках единой формы с валидацией по схеме
- Построила таблицы транзакций с серверной пагинацией и фильтрацией, обрабатывающие более 10 000 записей на административной стороне, с использованием TanStack Query для кэширования и дедупликации запросов
- Реализовала фильтр по диапазону дат с календарём на базе react-day-picker, интегрированный непосредственно в конвейер запросов транзакций
- Создала переиспользуемые компоненты боковой панели для деталей транзакции, независимые от состояния строк таблицы
- Использовала Zustand для глобального клиентского состояния (фильтры, сессия/роль) наряду с TanStack Query для серверного состояния, сохраняя чёткое разделение этих задач
- Разработала отдельные формы для чувствительных действий (смена email, смена пароля), требующие подтверждения текущим паролем, каждая со своей схемой Zod для валидации (например, совпадение полей нового пароля и его повтора)
- Реализовала валидацию форм в потоках правил перенаправления, API-ключей, управления аккаунтом и мерчантами с помощью React Hook Form + схем Zod, включая условную логику схем для обработки двух режимов перенаправления
- Использовала компоненты для построения графиков из Chakra UI для визуализации биллинга и использования
- Настроила клиентскую маршрутизацию с помощью react-router-dom для отдельных пользовательского и административного деревьев маршрутов
