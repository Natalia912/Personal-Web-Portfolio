## Описание проекта

Rocky Jam — приложение для музыкантов, позволяющее создавать, редактировать и воспроизводить музыкальные композиции. Создано на Vue 3, TypeScript и Quasar, с использованием Pinia для управления состоянием и TanStack Query для загрузки данных. Приложение включает простую аутентификацию по имени пользователя/паролю с JWT, галерею композиций, структурированный редактор композиций и движок воспроизведения с синхронизацией метронома. Лёгкий бэкенд на FastAPI + PostgreSQL отвечает за хранение композиций — я разработала его самостоятельно, после чего он был проверен и доработан бэкенд-разработчиком.

### Ключевые функции

- **Галерея композиций** — главный экран со списком всех доступных композиций, каждую из которых можно открыть для редактирования
- **Редактор композиций** — композиции строятся из секций, каждая из которых представлена в виде блока; внутри секции пользователи добавляют аккорды через всплывающую форму, указывая название аккорда и длительность, а также настройки уровня секции — размер такта, длительность, название секции и количество повторов
- **Воспроизведение с метрономом** — композиции можно воспроизводить с синхронизированным метрономом; каждый аккорд визуализируется как блок, перемещающийся справа налево по мере воспроизведения
- **Управление воспроизведением** — пользователи могут останавливать и возобновлять воспроизведение в любой момент, а также регулировать BPM метронома во время воспроизведения
- **Аутентификация** — простой вход по имени пользователя и паролю, защищённый JWT-токенами

### Технические особенности

- Разработала структурированную модель данных редактора композиций (секции, содержащие аккорды, каждый с метаданными длительности, размера такта и повторов), а также соответствующий UI для её редактирования
- Реализовала процесс создания/редактирования аккордов через всплывающую форму
- Расширила уже существующий движок воспроизведения (изначально созданный другим разработчиком команды), со временем добавляя к нему новые функции
- Использовала Pinia для состояния композиций/редактора и TanStack Query для синхронизации серверного состояния с бэкендом
- Создала бэкенд на FastAPI + PostgreSQL для CRUD-операций с композициями (создание, редактирование, удаление), впоследствии проверенный и улучшенный совместно с бэкенд-разработчиком
- Реализовала процесс аутентификации на основе JWT как на фронтенде, так и на бэкенде
