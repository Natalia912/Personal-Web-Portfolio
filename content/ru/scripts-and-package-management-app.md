## Описание проекта

Облачная платформа, созданная на Vue.js и фреймворке Quasar, которая позволяет командам AEC (архитектура, инжиниринг и строительство) развертывать, документировать и контролировать свои скрипты автоматизации Dynamo и Grasshopper в масштабах всей организации.

### Ключевые функции

- **Управление версиями и пакетами** — закрепление точных версий пакетов за рабочими пространствами, чтобы скрипты выполнялись с согласованными зависимостями независимо от локального окружения пользователя
- **Инспектор запусков и история версий** — отслеживание истории выполнения и просмотр изменений с течением времени, что дает командам полную прозрачность того, как развиваются скрипты
- **Блочный редактор Wiki** — редактор документации в стиле Notion/GitBook для создания структурированных документов по каждому скрипту прямо внутри платформы
- **Консоль управления организацией** — административный интерфейс для пользователей, ролей, групп и прав доступа к рабочим пространствам, с массовым импортом CSV и синхронизацией групп Azure AD
- **Настройка QuickAccess** — редактор макета с перетаскиванием для наиболее используемых скриптов пользователя, синхронизируемый в реальном времени с лентой Revit
- **Дашборды аналитики использования** — визуальная отчетность по показателям успешности запусков, тенденциям внедрения и состоянию скриптов в рамках всей организации

### Технические особенности

- Спроектировала и построила весь фронтенд самостоятельно на Vue.js и Quasar, от первоначальных моделей данных до релиза в продакшн
- Создала кастомный блочный редактор документов на основе Editor.js для функции документации Wiki
- Разработала кастомный движок drag-and-drop для панели QuickAccess с поддержкой вложенных групп и синхронизацией в реальном времени с лентой Revit
- Реализовала 7 визуализаций на D3.js для дашбордов аналитики, каждая со своей структурой данных и логикой рендеринга
- Внедрила аутентификацию через Microsoft SSO и по email/паролю, с управлением сессиями на основе JWT
- Оптимизировала загрузку данных с помощью подгрузки по требованию и стратегий кэширования для поддержания отзывчивости интерфейса при больших объемах данных
